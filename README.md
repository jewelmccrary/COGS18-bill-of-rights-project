# Bill of Rights Study Tool

This project is a Python-based tool that helps users study for the AP US Government and Politics exam.
It allows users to learn and test their knowledge of the Bill of Rights.

## Features
- Quiz on amendment descriptions
- Quiz on Bill of Rights ratification date
- Quiz on AP-Gov-required Supreme Court cases related to the Bill of Rights

## How to run
1. Open the Jupyter Notebook
2. Run all cells from top to bottom
3. Create a `StudyingBillOfRights` object and start studying

## Files included
- ProjectNotebook.ipynb
- module.py (contains the main StudyingBillOfRights class)
- tests.py (unit tests for StudyingBillOfRights class)
